SLIDE 26 / 30 · REAL-TIME INFRASTRUCTURE
ZERO-REFRESH SYNCHRONIZATION

MULTI-DEVICE CLOUD SYNC

Bookings created on a traveler's mobile phone appear instantaneously on agency admin screens via Server-Sent Events (SSE) and persistent cloud storage with browser cache failover.

01 · TRAVELER CLIENT (REACT 18 + VITE)

Optimistic state updates, localStorage persistence, and automatic background sync queue.

02 · EXPRESS API & SSE STREAM (/api/events)

Broadcasts booking-created, booking-deleted, and catalog price updates to all connected screens.

03 · PERSISTENT CLOUD & SQL STORAGE

Dual-write JSON cloud snapshot (wanderlust_cloud_db.json) + structured SQL schema.

04 · AGENCY ADMIN PORTAL

Receives live push updates without page reloads and exports verified reports.
